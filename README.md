# What is Crystal Bitoreum?

**Crystal Bitoreum** is a full, independent fork of the original Bitoreum project.

The last known communication from the original lead developer occurred on **May 3rd, 2023**, after which no updates followed. Given the extreme amount of time lapsed, we feared the worst. Rather than watch the project fade into obscurity, we’ve chosen to carry it forward — maintaining, fixing, and building upon what was already a promising chain with a passionate community.

## Mission Statement

Crystal Bitoreum retains the original `$BTRM` token. Our mission is to:

- Fix known issues present in the original 3.0.2.1 `Transilvania` core
- Transparently fund future development using post-fork dev fees [Transparency Portal](http://localhost:4321/accounting)
- Build a collaborative and resilient team to ensure the project endures
- Maintian helathy mining partnerships
- Maintain & expand Exhange presence

We understand that this token has already been mined to some degree. While this technically breaks the "no pre-mine" ideal, we believe honesty and transparency are more valuable than clinging to a narrative. This is a continuation, not a reboot.

## A Word on Community

Yes, the formation of Bitoreum was surrounded by drama. That ends now.

Our focus is on supporting the community who remained, welcoming new members, working with exchanges, and building partnerships across the broader crypto space.

## Excerpt from the Original Bitoreum Project

> Bitoreum is a decentralized financial technology accessible to everyone — fast, secure, and with negligible fees.  
> It has its own blockchain based on the Raptoreum codebase, featuring ASIC-resistant PoW and Smartnodes for enhanced network security.  
> Mining is available via both CPU and GPU. Privacy is preserved with CoinJoin functionality integrated directly in the wallet.

### Original Goals

- Launch mobile wallets for Android and iOS.
- Offer a crypto payment gateway for small businesses.
- Deploy Bitoreum Exchange — a blockchain-based exchange to lower listing barriers.
- Enable Smartnode-based passive income with modest investment.

## Immediate Roadmap

1. **Stabilize the core software** — address all known bugs in 3.0.2.1
2. **Re-enable pool support** — maintaining mining compatibility
3. **Release public binaries** — for miners, node operators, and exchanges
4. **Transition existing SmartNodes** — seamless migration to the new 4x core
5. **Activate transparent dev fee reporting** — published quarterly
6. **Expand the developer team** — funded from the post-fork dev fee

We’ll publish a full roadmap soon at [https://www.bitoreum.cc](https://www.bitoreum.cc).

## Development Process

- The `main` branch is always stable
- Active work is done in `dev` branch
- `dev` is merged with version head EX. `4.x`
- Releases are then tagged and documented clearly

Contributions are welcome — see [`CONTRIBUTING.md`](CONTRIBUTING.md) for guidelines.

---

## Testing & CI

Testing is crucial for the security and reliability of Crystal Bitoreum Core.

- Run unit tests with: `make check`
- Run functional tests: `test/functional/test_runner.py`

CI builds test each pull request on Linux, macOS, and Windows.

**All high-risk or significant changes should be reviewed and tested by another contributor.**
